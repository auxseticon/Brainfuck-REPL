My first-ever project is this brainfuck repl. It is fully made in CPP and has only one file.
It takes a string of brainfuck code (such as "++++++++[>++++[>++>+++>+++>+<<<<-]>+>+>->>+[<]<-]>>.>---.+++++++..+++.>>.<-.<.+++.------.--------.>>+.>++.") and interprets it character by character.

That is literally it, it just applies the correct operation per character, and goes to the next.
